# Data Notice

The public dataset is distributed separately through Tsinghua Cloud as `SuperShip-public-data.tar.zst`. After extraction, the data under `data/SuperShip/` contains only the public training, validation, and 200-image reference splits.

The 4,300-image hidden evaluation split is not part of this repository. Do not attempt to reconstruct, redistribute, or use hidden evaluation data outside the organizer-controlled evaluation environment.
